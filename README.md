# CineRoulette 🎰

Интерактивная рулетка для выбора фильмов, сериалов и анимации в стиле казино.

## Особенности

- Современный дизайн в стиле казино с неоновыми эффектами
- Система фильтров: тип контента, рейтинг, год выпуска
- Анимированная слот-машина с жанрами
- База из 50 фильмов, сериалов и анимации
- Адаптивный дизайн для мобильных устройств
- Эффекты конфетти при выигрыше

## Как использовать

1. Откройте `index.html` в браузере
2. Настройте фильтры (опционально):
   - Выберите тип контента: Фильм, Сериал, Анимация или Всё
   - Установите минимальный рейтинг
   - Укажите диапазон годов выпуска
3. Нажмите кнопку "КРУТИТЬ"
4. Дождитесь остановки барабанов с жанрами
5. Получите рекомендацию фильма на основе выпавших жанров и ваших фильтров

## Технологии

- HTML5
- CSS3 (анимации, градиенты, стеклянные эффекты)
- Vanilla JavaScript

## Запуск

Просто откройте файл `index.html` в любом современном браузере.

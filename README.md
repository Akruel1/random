# Genre Jackpot

Современный статический сайт в стиле казино-рулетки: выбираешь базовые фильтры (тип, рейтинг, год), крутишь “777”-барабаны жанров и получаешь подходящий фильм/сериал/анимацию с постером, названием и описанием.

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.
